# SD 卡媒体索引

原生实现位于 `components/media/media_library.cpp` 和 `media_cache.cpp`。启动尝试加载 SD 卡根目录的 `/.esp-story-index.bin`；缺少、损坏或存在 `/.esp-story-index.dirty` 时不信任缓存，进入媒体页面或手动刷新时扫描 `/music` 和 `/story`。页面使用内存目录快照，打开故事时再读取时间轴和图片。

索引包含版本、边界和校验信息。保存使用临时文件、备份及恢复机制；扫描失败或超限不会发布不完整目录。FAT 断电时仍可能发生文件系统损坏。USB 写入开始时标记索引失效；传输结束后，设备空闲且存储版本变化时尝试刷新。电脑直接改卡不会更新设备运行中的版本，请重新启动或在设置中刷新。

视频不进入音乐/故事索引。视频列表首次进入时扫描 `/video`，之后按存储版本缓存；USB 维护期间不扫描，失败保留旧快照并在下次进入重试。电脑直接改卡后需重启以重新发现视频。

当前扫描上限为 300 首音乐、32 个音乐分类、128 个故事条目；图文故事按文件夹、音频故事按 MP3 计数。实际策略边界和失败提示以代码为准。索引扫描仍同步执行，刷新时需停止播放；更换 TF 卡请先关闭设备。

运行 `bash tools/test_host.sh` 验证目录、索引、损坏恢复与视频缓存逻辑。真实 FAT、拔卡、断电恢复和播放互斥仍需实机验收。
