# 故事小镇主页

主页沿用现有四个入口及顺序：音乐、故事、童谣、设置。旋钮或 NEXT/LAST 切换，OK / 编码器短按进入，业务逻辑保持在 `main.cpp`。

画面为 320×240：顶部品牌及状态栏，左侧主题名称和探索按钮，右侧 128×128 插画，底部彩色车票导航。四个主题分别为音乐舞台、故事森林、童谣花园、工具小屋。卡片检测和童锁标识保留，音量更新不重画插画。

## 资源生成

`docs/icons/home-scenes.png` 是四宫格透明插画原图，依次为小熊舞台、树屋、小鸟、猫头鹰工坊。

```sh
python3 tools/build_home_scenes.py
```

脚本依赖 Pillow，将各象限缩至 128×128，合成各自主题底色并生成 `src/home_scenes.h`。四幅图合计 131072 字节，使用现有 LovyanGFX 默认 swap565 字节序，以只读数组存放在 Flash。运行时不依赖 TF 卡、PNG 解码或图像缩放。更改主题底色时须同步脚本中的背景值并重新生成，避免插画出现方形色差。

文字使用固件现有的 efont 16/14/12 像素字体。HTML 设计稿使用 VLW 字库，因此实际点阵字形与设计稿略有不同。切换主题时重绘 PSRAM 合成画布，由现有 `Display::present` 差分提交；没有选择或音量变化时不重绘。未新增全屏缓冲区。

## 编译验证

本次使用临时配置指定 `platform = espressif32@6.12.0`（Arduino 2.0.17）完成编译和链接：静态 RAM 155596 字节，Flash 2461473 字节。仓库原配置没有固定平台版本，未在此次主页修改中调整；全新安装可能选中 Arduino 3.x，而现有背光等驱动仍使用 2.x 接口。尚未进行实体屏幕和旋钮测试。
