# 显示刷新

IDF UI 任务通过 `Display::canvas()` 绘制，`src/display.cpp` 在 PSRAM 可用时使用 320×240 RGB565 画布和上一帧比较缓存，共约 300 KiB。普通页面按 8 行条带比较变化范围；无变化不发送像素。PSRAM 或内存分配失败时回退直接绘制。

两个内部 DMA 暂存区各 5 KiB：准备下一条带时可与上一条带 SPI 传输重叠，复用前及结束前等待 DMA。视频模式跳过差异比较并提交整帧；离开视频后强制重建比较缓存。视频 UI 以 33.334 ms 为循环预算，绘制和 SPI 时间计入预算；超时仍短暂阻塞，让其他任务运行。渲染不会与面板扫描同步，不能保证无撕裂。

当前 SPI 时钟为 40 MHz，320×240 RGB565 满屏像素的理论传输下限约 30.72 ms，实际帧率还受 SD、解码、合成和调度影响。视频缓存和任务详见 [播放器文档](idf-video-player.md)。

使用 `bash tools/test_host.sh` 检查差异区域和帧预算，使用 README 中的 `idf.py build` 构建。颜色、旋转、撕裂、音频连续性和真实刷新耗时按 [真机验收清单](idf-hardware-acceptance.md) 测试。
