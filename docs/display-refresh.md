# Buffered UI refresh

UI drawing uses `Display::canvas()`. When PSRAM is available, this is a
320×240 RGB565 Sprite. `Display::present()` compares it with the last submitted
image in eight-row strips and sends only each strip's changed horizontal span.
An unchanged image sends no pixel data. This scans the image at most once per
33ms; it does not maintain a manually invalidated widget tree.

Memory is allocated once: approximately 300 KiB PSRAM for the canvas and previous
image, plus 5 KiB internal DMA-capable SRAM for transmission. The previous image
is a comparison cache, not an asynchronously displayed second framebuffer.
Each packed strip uses `pushImageDMA()` followed by `waitDMA()` before reuse.
Sprite byte order is preserved through `lgfx::swap565_t`.

The main loop submits after page drawing, including early-return paths. Blocking
startup and story-open operations explicitly submit their loading screen first.
Only the main task may draw or submit. Both supported rotations remain 320×240;
rotation invalidates the entire submitted-image cache. If allocation fails,
drawing falls back to the LCD and startup prints the fallback status.

Music updates run every 33ms. Both title marquees move at 28 pixels/second with
two-second pauses at each endpoint; unchanged integer offsets are not redrawn.
The actual display rate depends on rendering and SPI time. SPI remains 40MHz.
JPEG loading/decoding still blocks the main task; prefetch is not implemented.
Buffering hides erase/redraw intermediate states but does not synchronize with
the panel scan, so it does not guarantee tear-free full-screen transitions.

## Verification

Host checks:

```sh
g++ -std=c++11 -Wall -Wextra -pedantic -fsanitize=address,undefined \
  test/render_math_test.cpp -o /tmp/esp-story-render-test
/tmp/esp-story-render-test
```

Build with the project's PlatformIO environment. Hardware acceptance remains:

- Confirm `[UI] PSRAM canvas: OK` at startup and correct red/blue colors.
- Rapidly turn the encoder in lists, including crossing the four-row boundary.
- Check long music/story titles, both endpoint pauses, and pause/volume feedback.
- Change brightness, selection and rotation in settings; check for stale shadows.
- Play audio while switching JPEG panels and returning from settings; check for
  audio dropouts, missing bottom-bar regions, tearing and input stalls.
- Verify boot/error/loading screens remain visible before blocking operations.

The font assets have not been regenerated by this rendering change.
