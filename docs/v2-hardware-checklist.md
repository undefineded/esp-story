# V2.0 硬件评审清单

依据：`Netlist_Schematic1_1_2026-11-06-V2.0.enet`（183 元件，EasyEDA Pro 网表）。
范围：只依据网表（连接关系），不含 PCB 布局；天线、铜皮、ESD、温升需结合 PCB 与实物复核。

用法：投板前逐项勾完 A/B；打样回板后按 C 做 bring-up。

---

## A. 必改项（不解决不能投板/不能出声）

### A1. 固件与 V2.0 引脚错配

- [ ] 新增 `v2` board profile（现固件只有 `legacy`，引脚按 V1 定义）
- [ ] 按键改为 TCA8418（I2C 0x34，INT# → **IO21**），实现 8 键矩阵：UP/DOWN/LEFT/RIGHT/OK/MINUS/ADD/HOME（ROW0-4 × COL0-2）
- [ ] 交互从"旋钮"改为"按键"的产品方案定稿（选曲/音量/翻页的按键映射）
- [ ] **功放使能**：`MAX_SD = IO15`，R1 10K 下拉到 GND，**默认静音**；固件必须在开播前把 IO15 拉高，否则 V2 上完全没有声音
- [ ] PN532：复位 `RSTPD = IO48`（R59 10K 上拉到 3V3_1），IRQ = `IO39`
- [ ] 麦克风：ICS-43434 的 SD → **IO47**，与功放共用 BCLK=IO16 / LRCLK=IO17，需要 **I2S 全双工 RX**（当前只有 TX）
- [ ] USB 在位检测：`USB_PRESENT_N = IO42`（TPS2116 ST，R17 10K 上拉）；注意 ST 表示"哪一路输入被选中"，不等于 USB 插入
- [ ] 霍尔：`HALOUT = IO40`，经 R29 10R，**开漏无外部上拉** → 固件需开内部上拉
- [ ] FRAM 地址：FM24CL64 A0=3V3 → **0x51**；EEPROM AT24C512 为 **0x50**。当前"0x50–0x57 逐个写读探测"可能先命中 EEPROM 并写入，建议固定探测 0x51
- [ ] 新外设驱动（可选但建议）：RTC RX8900(0x32)、光感 BH1750(0x5C)、INA226(0x40) 电量

**引脚对照（V1 固件 → V2.0 实际）**

| 功能 | V1 固件 | V2.0 网表 | 结论 |

| LCD SCK/MOSI/DC/RST/CS/BL | 5/4/6/7/8/9 | 5/4/6/7/8/9 | ✅ 一致 |
| SD CLK/CMD/DAT0 | 12/11/13 | 12/11/13 | ✅ 一致（另走 4-bit：14/38/10） |
| I2S BCLK/LRCLK/DIN | 16/17/18 | 16/17/18 | ✅ 一致 |
| I2C SDA/SCL | 1/2 | 1/2 | ✅ 一致 |
| OK / NEXT / LAST | 47/48/39 | 麦克风 / PN532 复位 / PN532 IRQ | ❌ 需改 |
| 编码器 A/B/SET | 14/15/21 | SD_DAT1 / 功放 SD / 键盘 INT | ❌ 需改 |
| 霍尔 | 40 | 40 | ✅ 一致 |

### A2. 3.3V 用 LDO 从 5V 降：热与效率

- [ ] 统计 3.3V 实际负载电流（ESP32-S3 峰值 + LCD + TF + PN532 + 外设）
- [ ] 按 5V→3.3V、SOT-23-5（θJA≈200°C/W）核算结温：`P = (5-3.3) × I`，密封外壳按 40°C 环境算
- [ ] 若 250 mA 以上，改方案：3.3V 用 buck，或让 `TPS63802` 直接出 3.3V、只给功放单独升 5V
- [ ] 至少实测满载 30 分钟，确认 `U10 TLV75733` / `U22 XC6220` 不触发过温保护

### A3. BOM 缺口

- [ ] `R6`（MAX98357 `GAIN_SLOT` → GND）**无阻值**：按需要的增益选值并写入 BOM（悬空与 0Ω 的增益不同）

## B. 投板前确认（逐项勾）

### B1. 上电与启动

- [ ] `IO45`（VDD_SPI strap）**悬空** → 建议加 10K 下拉
- [ ] `IO46` 已有 R8 10K 下拉 ✅（保持）
- [ ] `IO0` BOOT：R21 10K 上拉 + SW3 ✅；`EN`：R22 10K + C20 1µF + SW2 ✅
- [ ] `IO3`、`IO35/36/37` 悬空 —— 确认无用途（IO3 为 strap，默认上拉可接受）

### B2. 射频与天线

- [ ] U1 为 `ESP32-S3-WROOM-1U`（IPEX 版，**无板载天线**）：确认是 PCB 天线（含匹配）还是漏了 IPEX 座 + 匹配网络
- [ ] PN532 天线：TX1/TX2 经 L1/L4 560nH + C16/C17 调谐、R64/R65 接收网络 ✅；确认天线阻抗与读卡距离

### B3. 显示与背光

- [ ] 背光：`LEDA` 经 R19 仅 2.2Ω 直连 3.3V，Q1 低边开关，**无恒流** → 按屏规格核算 LED 电流，必要时改恒流或调整 R19
- [ ] `RESET`（U8 pin2 → IO7）无上拉：确认屏模组自带
- [ ] `CS` 有 R25 10K 上拉 ✅；`D/C`、`SCL/SDA_SCREEN` 无上拉（固件先初始化即可）

### B4. I2C 与地址

- [ ] 总线 7 器件 + 2 排针，上拉 R23/R24 4.7K：按走线电容评估 400 kHz 是否够快，必要时 2.2K 或降到 100 kHz
- [ ] 地址复核：EEPROM 0x50 / FRAM 0x51 / TCA8418 0x34 / RX8900 0x32 / INA226 0x40 / BH1750 **0x5C** / PN532 0x24 —— 无冲突 ✅
- [ ] PN532 IRQ 上拉 `R67 = NC`：确认 P70_IRQ 为推挽输出

### B5. 存储与其它

- [ ] TF 卡走 4-bit（DAT1=IO14、DAT2=IO38、DAT3=IO10），固件当前 1-bit：确认卡座/走线，并为将来 4-bit 留出验证
- [ ] `OUT1`（IO41）为**单点悬空网络**：删除或接入实际用途
- [ ] 充电链路：HE3342（U16）5V 充电、NTC R47 10K、充电/充满灯 LED2 ✅；确认充电电流设定值
- [ ] 电池：`U6` 接口 + R31 10mΩ（INA226 采样）+ SW8 电源开关；确认电池保护板规格

## C. 回板 bring-up 验收

- [ ] 3.3V / 3V3_1 / 5V 空载与满载电压、纹波
- [ ] USB 与电池双路切换（TPS2116），插拔 USB 不断电重启
- [ ] 充电电流、截止电压、NTC 保护、双色灯状态
- [ ] ESP32 下载/启动、串口日志；WiFi/BT 距离与 RSSI
- [ ] LCD 显示、背光 PWM 调光无啸叫；触摸/按键
- [ ] 喇叭出声（先拉高 IO15）、音量/EQ、无爆音
- [ ] TF 卡识别、读写速率（1-bit 20 MHz 实测应 ≥1 MB/s）
- [ ] 麦克风录音（I2S RX）底噪与灵敏度
- [ ] PN532 寻卡、I2C 通信、RSTPD 复位有效
- [ ] FRAM(0x51) 写读、EEPROM(0x50) 可读、RTC 走时与掉电保持
- [ ] 霍尔（IO40）开漏+内部上拉后的电平
- [ ] INA226 电压/电流读数与万用表对比
- [ ] 满载 30 分钟热测试：LDO、ESP32、充电 IC、功放表面温度
- [ ] 深睡/唤醒（若启用）电流
