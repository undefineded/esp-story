# PN532 与桌面端

PN532 和 FRAM 共用 I2C：SDA GPIO1、SCL GPIO2；PN532 地址为 `0x24`，模块与 ESP32 共地并使用适合模块的 3.3 V 供电。模块需设置为 I2C 模式。总线和板型配置以 `src/config.h`、`components/board/` 为准。PN532 的 IRQ/RST 接法取决于实际板卡；若模块在复位中拉住总线，可能需要硬件复位或重新上电。

当前原生实现位于 `components/nfc/`，产品入口在 `components/app/src/app.cpp`。服务探测 PN532 并维护模块和卡片状态；USB 产品配置通过 SBX4 v4 暴露 `nfc.status`。目前原生 USB 路由**仅支持状态查询**，其他 NFC 动作返回 `NOT_SUPPORTED`，模块不可用时返回 `NFC_UNAVAILABLE`。旧 Arduino 读写、NDEF、Classic 操作和其协议示例不代表 IDF 产品版已实现。

桌面端位于 `desktop/`，包含演示模式和比当前固件更完整的界面。真实设备可用功能以 hello 能力和固件响应为准；演示读写成功不等于实卡可用。开发命令见 [desktop/README.md](../desktop/README.md)，USB 文件操作见 [文件传输](file-transfer-refactor.md)。

验收时使用启用 USB 的产品固件，分别检查模块缺席、连接模块、放卡和移卡的状态响应，再核对设备复位、共享 I2C 和长时间轮询是否影响其他功能。实卡写入尚不属于当前 USB 验收范围。已有板卡观察见 [真机验收记录](idf-acceptance-log.md)。
